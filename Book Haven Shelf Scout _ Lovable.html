how to project push on github

Today at 9:19 AM
Explained how to connect and sync the project to GitHub

To push your Shelfwise project to GitHub:

  1. Open Project settings → Git in Lovable.
  2. Choose GitHub and connect your GitHub account.
  3. Authorize Lovable, then select your account or organization.
  4. Connect the project—Lovable creates a new private repository and uploads your code.

After connecting, changes made in Lovable sync automatically to GitHub; you don’t need to push manually.
